# Contributing Guidelines

Thank you for your interest in improving `facebook-playwright-mcp`!

## Development Workflow
1. Fork the repository and create your feature branch:
   ```bash
   git checkout -b feature/my-new-feature
   ```
2. Set up an editable development installation:
   ```bash
   pip install -e .
   ```
3. Test your changes locally before opening a pull request.
4. Submit your pull request with a clear description of your changes.

## Guidelines
- Write clean and well-structured code.
- Never commit private credentials or personal session files.
- Keep dependency additions minimal and justified.
